# Adoption and First Use

Release target: **AI-Codex v1.1.0**

Authoritative lifecycle status is external to this immutable payload and is resolved through the applicable Promotion Record.

## For a new project

1. Read [index.md](index.md) and the normative corpus it links.
2. Pin the exact published AI-Codex release (`v1.1.0`) and public repository identity.
3. Create the project's adoption declaration with required configurable choices, Actor→Role assignments, review topology, repository/publication settings, and integration permissions.
4. Treat every normative `MUST` as Dogma for an AI-Codex-compliant project.
5. Put project-specific accepted decisions in Project Canon, not in this package.
6. For each versioned Canon component, reserve the declared Canon namespace for promoted material and use `R001`, `R002`, ... for Canonical Revisions.
7. Generate/validate FORMAT-2 for the current Canon revision and keep Markdown as the authored authoritative representation.
8. Use the versioned open-loop envelope schemas for new TASK, Review Assignment, and transported Service Memo artifacts.
9. Give zero-memory Compiler/Reviewer participants the required bootstrap parameters. Successful Codex onboarding is acknowledged minimally, not unsolicitedly summarized.
10. If desired, opt into the shipped `Researcher` (Compiler) or `Skeptic` (Reviewer) Role Context Profile per workstream.

## Minimal instruction to an AI participant

A project should be able to say, in substance:

> Before beginning work, read the adopted AI-Codex and operate under it. Your assigned role for this workstream is: <ROLE>.

The project-specific assignment then supplies only the parameters the Codex deliberately leaves configurable, such as exact Candidate revision, Reviewer count, authorized context, repository permissions, and output location.

## Migrating from v1.0.0

Projects moving from v1.0.0 should follow [MIGRATION-v1.0.0-to-v1.1.0.md](MIGRATION-v1.0.0-to-v1.1.0.md). Migration is explicit and does not retroactively alter the compliance status or provenance of historical decisions.
